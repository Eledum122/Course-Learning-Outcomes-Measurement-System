1️⃣ تثبيت المكتبات - INSTALLING LIBRARIES

إذا كنت تستخدم البيئة الافتراضية (.venv):
If you're using a virtual environment (.venv):

   A. تفعيل البيئة الافتراضية - Activate Virtual Environment:
      في PowerShell:
      .venv\Scripts\Activate.ps1

      في Command Prompt:
      .venv\Scripts\activate.bat

   B. تثبيت المكتبات - Install Libraries:
      .venv\Scripts\python.exe -m pip install -r requirements.txt

إذا كنت تستخدم Python العام (بدون بيئة افتراضية):
If you're using global Python (without virtual environment):

   python -m pip install -r requirements.txt

2️⃣ تشغيل البرنامج - RUNNING THE APPLICATION

⭐ الطريقة الموصى بها - RECOMMENDED METHOD:

   إذا كنت تستخدم البيئة الافتراضية (.venv):
   If using virtual environment:

      اضغط مرتين على - Double-click:
      START_WITH_VENV.bat

   إذا كنت لا تستخدم البيئة الافتراضية:
   If NOT using virtual environment:

      اضغط مرتين على - Double-click:
      START_HERE.bat

📌 طرق بديلة - Alternative Methods:

   في VSCode Terminal (مع البيئة الافتراضية):
   In VSCode Terminal (with venv active):

      python main.py

   في PowerShell (مع البيئة الافتراضية):
   In PowerShell (with venv):

      .venv\Scripts\python.exe main.py

   في PowerShell (بدون بيئة افتراضية):
   In PowerShell (without venv):

      python main.py

3️⃣ حل المشاكل - TROUBLESHOOTING

❌ المشكلة: ModuleNotFoundError: No module named 'tkcalendar'
   (أو أي مكتبة أخرى)

   ✅ الحل - Solution:

      1. تأكد من تفعيل البيئة الافتراضية إذا كنت تستخدمها
         Make sure virtual environment is activated if you're using it

      2. أعد تثبيت المكتبات - Reinstall libraries:

         مع البيئة الافتراضية - With venv:
         .venv\Scripts\python.exe -m pip install -r requirements.txt

         بدون بيئة افتراضية - Without venv:
         python -m pip install -r requirements.txt

      3. إذا استمرت المشكلة - If problem persists:

         .venv\Scripts\python.exe -m pip install tkcalendar --force-reinstall

❌ المشكلة: نافذة الدخول لا تظهر - Login window doesn't appear

   ✅ الحل - Solution:

      1. استخدم START_WITH_VENV.bat (إذا كان لديك .venv)
         أو START_HERE.bat (بدون .venv)

      2. تأكد من تثبيت جميع المكتبات المطلوبة
         Make sure all required libraries are installed

      3. شغل التشخيص - Run diagnostics:
         .venv\Scripts\python.exe diagnose.py
