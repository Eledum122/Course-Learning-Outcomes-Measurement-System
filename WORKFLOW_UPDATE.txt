🎯 سير العمل الجديد - NEW WORKFLOW
═══════════════════════════════════════════════════════════════════════════════

الخطوة 1️⃣: إنشاء البرنامج الأكاديمي
Step 1: Create Academic Program
────────────────────────────────────────
قائمة "الإدارة" → "إدارة البرامج الأكاديمية" (Ctrl+P)
Admin Menu → Academic Programs (Ctrl+P)

• ➕ برنامج جديد / New Program
• املأ المعلومات / Fill information:
  - الجامعة / University
  - الكلية (عربي وإنجليزي) / College (Arabic & English)
  - القسم (عربي وإنجليزي) / Department (Arabic & English)  ⭐ مهم!
  - اسم البرنامج (عربي وإنجليزي) / Program Name (Arabic & English)
  - رمز البرنامج / Program Code
  - الوصف / Description
• ✓ حفظ / Save

⚠️ ملاحظة: لن يظهر حقل "منسق البرنامج" في هذا النموذج
   Note: "Program Coordinator" field will NOT appear in this form

الخطوة 2️⃣: إضافة أعضاء هيئة التدريس للقسم
Step 2: Add Faculty Members to Department
────────────────────────────────────────
قائمة "الإدارة" → "إدارة أعضاء هيئة التدريس" (Ctrl+F)
Admin Menu → Faculty Management (Ctrl+F)

• ➕ عضو جديد / New Member
• املأ المعلومات / Fill information:
  - الرقم الوظيفي * / Employee ID *
  - الاسم * / Name *
  - الدرجة العلمية * / Academic Degree *
  - التخصص العام * / General Specialization *
  - التخصص الدقيق / Specific Specialization
  - الكلية (عربي) * / College (Arabic) *  ⭐ يجب أن تطابق البرنامج
  - الكلية (إنجليزي) / College (English)
  - القسم (عربي) * / Department (Arabic) *  ⭐ يجب أن تطابق البرنامج
  - القسم (إنجليزي) / Department (English)
  - البريد الإلكتروني / Email
  - الهاتف / Phone
  - رقم المكتب / Office Number
  - ☑ نشط / Active
• 💾 حفظ / Save

⚠️ مهم جداً: تأكد أن القسم (عربي) يطابق تماماً القسم المحدد في البرنامج!
   VERY IMPORTANT: Ensure Department (Arabic) exactly matches the program's department!

كرر هذه الخطوة لجميع أعضاء القسم
Repeat this step for all department members

الخطوة 3️⃣: تعيين منسق البرنامج
Step 3: Assign Program Coordinator
────────────────────────────────────────
قائمة "الإدارة" → "إدارة البرامج الأكاديمية" (Ctrl+P)
Admin Menu → Academic Programs (Ctrl+P)

• اختر البرنامج من القائمة / Select program from list
• 👤 تعيين منسق / Assign Coordinator
• ستظهر نافذة تحتوي على:
  Will show window with:
  - معلومات البرنامج / Program information
  - قائمة أعضاء القسم فقط (النشطين) / Department members only (active)
• اختر المنسق المناسب / Select appropriate coordinator
• ✓ تعيين / Assign

⚠️ ملاحظات مهمة - IMPORTANT NOTES
═══════════════════════════════════════════════════════════════════════════════

1. التطابق الدقيق للقسم
   Exact Department Matching
   ────────────────────────
   يجب أن يكون اسم القسم (عربي) في عضو هيئة التدريس مطابقاً
   تماماً لاسم القسم في البرنامج الأكاديمي.

   The department name (Arabic) in faculty member must exactly match
   the department name in the academic program.

   مثال / Example:
   ✓ الصحيح: "قسم الإحصاء" = "قسم الإحصاء"
   ✗ الخطأ: "قسم الإحصاء" ≠ "الإحصاء"
   ✗ الخطأ: "قسم الإحصاء" ≠ "قسم الاحصاء" (بدون همزة)

2. الترتيب الصحيح
   Correct Order
   ────────────────────────
   يجب إضافة أعضاء القسم قبل تعيين المنسق
   Must add department members BEFORE assigning coordinator

   إذا حاولت تعيين منسق ولا يوجد أعضاء في القسم، ستظهر رسالة:
   If you try to assign coordinator with no department members, you'll see:
   "لا يوجد أعضاء نشطون في هذا القسم"
   "No active faculty members in this department"

3. تعديل المنسق
   Changing Coordinator
   ────────────────────────
   يمكنك تغيير المنسق في أي وقت من خلال:
   You can change the coordinator anytime by:
   - اختيار البرنامج / Select program
   - 👤 تعيين منسق / Assign Coordinator
   - اختيار عضو آخر / Select different member

4. حذف المنسق
   Removing Coordinator
   ────────────────────────
   لا يوجد خيار "بدون منسق" في نافذة التعيين
   There is no "No Coordinator" option in assignment window

   إذا أردت إزالة المنسق:
   If you want to remove coordinator:
   - استخدم "✏️ تعديل" في نموذج البرنامج
   - Use "✏️ Edit" in program form
   - أو قم بتعيين منسق آخر
   - Or assign a different coordinator
