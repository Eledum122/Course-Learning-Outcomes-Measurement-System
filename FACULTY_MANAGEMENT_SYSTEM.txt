📋 ملخص النظام - SYSTEM SUMMARY
═══════════════════════════════════════════════════════════════════════════════

تم إنشاء نظام كامل لإدارة أعضاء هيئة التدريس مع الربط الكامل مع نظام البرامج
الأكاديمية، بحيث يتم اختيار منسق البرنامج من أعضاء القسم نفسه.

A complete Faculty Management System has been created with full integration
with the Academic Programs System, allowing program coordinators to be selected
from department faculty members.

🎯 سير العمل الجديد - NEW WORKFLOW
═══════════════════════════════════════════════════════════════════════════════

الخطوة 1️⃣: إنشاء البرامج الأكاديمية (بدون تحديد منسق)
────────────────────────────────────────────────────────
قائمة "الإدارة" → "إدارة البرامج الأكاديمية" (Ctrl+P)
• أدخل معلومات البرنامج:
  - الجامعة (افتراضي: جامعة تبوك)
  - الكلية (عربي وإنجليزي)
  - القسم (عربي وإنجليزي)
  - اسم البرنامج (عربي وإنجليزي)
  - اترك حقل "منسق البرنامج" على "-- بدون منسق --"
• احفظ البرنامج

Step 1️⃣: Create Academic Programs (Without Coordinator)
────────────────────────────────────────────────────────
"Admin" Menu → "Academic Programs" (Ctrl+P)
• Enter program information:
  - University (default: University of Tabuk)
  - College (Arabic and English)
  - Department (Arabic and English)
  - Program Name (Arabic and English)
  - Leave "Program Coordinator" as "-- No Coordinator --"
• Save the program

الخطوة 2️⃣: إدخال أعضاء هيئة التدريس
────────────────────────────────────────────────────────
قائمة "الإدارة" → "إدارة أعضاء هيئة التدريس" (Ctrl+F)
• أضف أعضاء هيئة التدريس:
  - الرقم الوظيفي *
  - الاسم *
  - الدرجة العلمية *
  - التخصص العام *
  - التخصص الدقيق
  - الكلية (عربي وإنجليزي) - مهم لربطه بالبرنامج
  - القسم (عربي وإنجليزي) - مهم لربطه بالبرنامج
  - البريد الإلكتروني
  - الهاتف
  - رقم المكتب
  - الحالة (نشط/غير نشط)

Step 2️⃣: Add Faculty Members
────────────────────────────────────────────────────────
"Admin" Menu → "Faculty Management" (Ctrl+F)
• Add faculty members:
  - Employee ID *
  - Name *
  - Academic Degree *
  - General Specialization *
  - Specific Specialization
  - College (Arabic and English) - Important for program linking
  - Department (Arabic and English) - Important for program linking
  - Email
  - Phone
  - Office Number
  - Status (Active/Inactive)

الخطوة 3️⃣: تعيين منسق للبرنامج
────────────────────────────────────────────────────────
عد إلى "إدارة البرامج الأكاديمية"
• اختر البرنامج
• اضغط "✏️ تعديل"
• ستظهر قائمة "منسق البرنامج" تحتوي فقط على:
  ✓ أعضاء القسم نفسه (قسم الإحصاء مثلاً)
  ✓ الأعضاء النشطين فقط
• اختر المنسق المناسب
• احفظ التعديلات

Step 3️⃣: Assign Program Coordinator
────────────────────────────────────────────────────────
Return to "Academic Programs"
• Select the program
• Click "✏️ Edit"
• The "Program Coordinator" list will show only:
  ✓ Members from the same department (e.g., Statistics Department)
  ✓ Active members only
• Select the appropriate coordinator
• Save changes

🔗 الربط بين الأنظمة - SYSTEM INTEGRATION
═══════════════════════════════════════════════════════════════════════════════

1. ربط القسم بالبرنامج
   ──────────────────────
   عند إنشاء/تعديل برنامج أكاديمي:
   • يتم تحديد القسم (department_ar)
   • عند اختيار منسق، يُعرض فقط أعضاء هذا القسم

   When creating/editing an academic program:
   • The department (department_ar) is specified
   • When selecting a coordinator, only members of that department are shown

2. معرّف المنسق في البرنامج
   ─────────────────────────
   قديماً: coordinator_id = user_id (من نظام المستخدمين)
   حالياً: coordinator_id = faculty_id (من أعضاء هيئة التدريس)

   Previously: coordinator_id = user_id (from Users system)
   Now: coordinator_id = faculty_id (from Faculty Members)

3. إمكانية الربط المستقبلية
   ────────────────────────────
   • يمكن ربط user_id مع faculty_id لإعطاء صلاحيات نظام
   • حقل user_id موجود في FacultyMember لهذا الغرض

   • user_id can be linked with faculty_id to grant system permissions
   • user_id field exists in FacultyMember for this purpose

⚠️ ملاحظات مهمة - IMPORTANT NOTES
═══════════════════════════════════════════════════════════════════════════════

1. القسم يجب أن يطابق تماماً
   ─────────────────────────────
   عند إضافة عضو هيئة تدريس، تأكد أن القسم (عربي) يطابق تماماً
   القسم المحدد في البرنامج الأكاديمي.

   When adding a faculty member, ensure the department (Arabic) exactly
   matches the department specified in the academic program.

2. الحالة النشطة
   ──────────────
   فقط الأعضاء النشطون يظهرون في قائمة المنسقين.
   Only active members appear in the coordinator list.

3. حذف عضو
   ─────────
   لا يمكن حذف عضو إذا كان منسقاً لبرنامج. قم أولاً بتغيير
   المنسق أو إزالته من البرنامج.

   Cannot delete a member if they are a program coordinator. First change
   or remove the coordinator from the program.

4. التوافق مع نظام المستخدمين
   ────────────────────────────
   حقل user_id موجود لربط عضو هيئة التدريس بحساب مستخدم
   في النظام (للاستخدام المستقبلي).

   The user_id field exists to link a faculty member with a user account
   in the system (for future use).
