## 📝 التحققات المطبقة (Applied Validations)

```
┌─────────────────────────────────────────────────────────────┐
│                   معلومات المقرر                            │
│                  Course Information                          │
├─────────────────────────────────────────────────────────────┤
│ ✓ اسم المقرر: غير فارغ                                    │
│ ✓ رمز المقرر: غير فارغ + فريد                              │
│ ✓ الشعب: غير فارغ                                          │
│ ✓ البرنامج: غير فارغ                                       │
│ ✓ العام الأكاديمي: غير فارغ                                │
│ ✓ المدرس: غير فارغ                                         │
│ ✓ المنسق: غير فارغ                                         │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                    نواتج التعلم                             │
│                 Learning Outcomes                            │
├─────────────────────────────────────────────────────────────┤
│ ✓ الكود: غير فارغ + فريد                                   │
│ ✓ الوصف: غير فارغ                                          │
│ ✓ الدرجة: > 0                                               │
│ ✓ معيار النجاح: 0-100                                      │
│ ✓ المستوى المستهدف: 0-100                                  │
│ ✓ مجموع الدرجات: = 100                                     │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                     الموضوعات                               │
│                       Topics                                 │

│ ✓ الرقم: فريد                                               │
│ ✓ العنوان: غير فارغ                                        │
│ ✓ ساعات الاتصال: > 0                                       │
│ ✓ مجموع الساعات الموزعة = ساعات الاتصال                   │
│ ✓ مجموع الدرجات: = 100                                     │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                   أنشطة التقييم                             │
│                Assessment Activities                         │
├─────────────────────────────────────────────────────────────┤
│ ✓ الاسم: غير فارغ + فريد                                   │
│ ✓ الدرجة: > 0                                               │
│ ✓ النسبة المئوية: 0-100                                    │
│ ✓ مجموع الدرجات: = 100                                     │
│ ✓ مجموع النسب المئوية: = 100%                              │
│ ✓ كل نشاط يقيس CLO واحد على الأقل                         │
```
