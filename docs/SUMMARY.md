## 🔧 كيفية الاستخدام | How to Use

### التثبيت السريع:
1. نسخ الملفات إلى المسارات الصحيحة
2. التأكد من وجود مجلد `data/courses`
3. استيراد الواجهة من الكود الرئيسي

### الاستخدام من الكود:
```python
from dialogs.stage1_course_dialog import Stage1CourseDialog
from managers.course_manager import CourseManager

cm = CourseManager()
dialog = Stage1CourseDialog(
    parent=main_window,
    course_manager=cm,
    current_user=current_user,
    course_id=None,
    language='ar'
)
```
