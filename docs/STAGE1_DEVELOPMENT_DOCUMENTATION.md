## 🎯 المكونات المطورة

### 1. نماذج البيانات (Data Models)
**الملف:** `models/course.py`

#### الفئات (Classes) المُنشأة:

1. **Semester (Enum)**
   - `FIRST`: الفصل الأول
   - `SECOND`: الفصل الثاني
   - `SUMMER`: الفصل الصيفي

2. **CLOCategory (Enum)**
   - `KNOWLEDGE`: المعرفة
   - `SKILLS`: المهارات
   - `VALUES`: القيم

3. **CourseInfo**
   - معلومات المقرر الأساسية
   - الحقول: اسم المقرر، رمز المقرر، الشعب، البرنامج، العام الأكاديمي، الفصل الدراسي، المدرس، المنسق، التاريخ
   - حالة الاعتماد (is_approved, approved_by, approved_date)

4. **CLO (Course Learning Outcome)**
   - نواتج تعلم المقرر
   - الحقول: الكود، الفئة، الوصف، PLOs المرتبطة، الدرجة، معيار النجاح، المستوى المستهدف
   - نتائج القياس: المستوى الفعلي، حالة التحقيق

5. **Topic**
   - موضوعات المقرر
   - الحقول: الرقم، العنوان، ساعات الاتصال، الدرجة، الملاحظات
   - توزيع على نواتج التعلم (CLO Distribution)

6. **AssessmentActivity**
   - أنشطة التقييم
   - الحقول: الاسم، الدرجة، النسبة المئوية، التوقيت
   - توزيع على الموضوعات
   - قائمة نواتج التعلم التي يقيسها النشاط

7. **TableOfSpecifications**
   - جدول المواصفات
   - يربط بين الموضوعات ونواتج التعلم وأنشطة التقييم
   - بنية ثلاثية الأبعاد: {topic_number: {clo_code: {activity_name: mark}}}

8. **Course**
   - النموذج الرئيسي للمقرر
   - يضم جميع المكونات السابقة
   - إدارة حالة المراحل (stage_1_completed, stage_1_approved, إلخ)
   - دوال التحقق من الصحة (validate_stage1)
   - دوال الحسابات (calculate_totals)

#### مميزات النماذج:
- ✅ تحويل من/إلى قاموس (to_dict, from_dict) للتخزين في JSON
- ✅ التحقق من صحة البيانات (validate)
- ✅ دعم كامل للغتين العربية والإنجليزية
- ✅ توثيق شامل بالعربية والإنجليزية
- ✅ معالجة الأخطاء المتقدمة

### 2. مدير المقررات (Course Manager)
**الملف:** `managers/course_manager.py`

#### الوظائف الرئيسية:

1. **إدارة دورة حياة المقرر:**
   - `create_course()`: إنشاء مقرر جديد
   - `save_course()`: حفظ المقرر
   - `load_course()`: تحميل مقرر
   - `delete_course()`: حذف مقرر
   - `course_exists()`: التحقق من وجود المقرر

2. **عمليات البحث والاستعلام:**
   - `list_all_courses()`: قائمة جميع المقررات
   - `get_courses_by_program()`: المقررات حسب البرنامج
   - `get_courses_by_semester()`: المقررات حسب الفصل الدراسي
   - `get_pending_approval_courses()`: المقررات بانتظار الاعتماد
   - `search_courses()`: البحث عن مقررات

3. **إدارة المكونات:**
   - `add_clo_to_course()`: إضافة ناتج تعلم
   - `remove_clo_from_course()`: حذف ناتج تعلم
   - `add_topic_to_course()`: إضافة موضوع
   - `remove_topic_from_course()`: حذف موضوع
   - `add_activity_to_course()`: إضافة نشاط تقييم
   - `remove_activity_from_course()`: حذف نشاط تقييم

4. **إدارة سير العمل (Workflow):**
   - `complete_stage1()`: إكمال المرحلة الأولى مع التحقق الكامل
   - `approve_stage1()`: اعتماد المرحلة الأولى
   - `reject_stage1()`: رفض المرحلة الأولى مع السبب

5. **الإحصائيات والتقارير:**
   - `get_course_statistics()`: إحصائيات تفصيلية للمقرر
   - `export_course_to_dict()`: تصدير المقرر
   - `import_course_from_dict()`: استيراد المقرر

#### نظام التخزين:
- 📁 التخزين في JSON files
- 📁 المسار: `data/courses/`
- 📁 تنسيق الملف: `{course_id}.json`
- 🔐 معالجة آمنة للملفات
- 🔄 نظام التحديث التلقائي للتواريخ

### 3. واجهة المستخدم (User Interface)
**الملف:** `dialogs/stage1_course_dialog.py`

#### التبويبات (Tabs):

1. **معلومات المقرر (Course Information)**
   - حقول إدخال للبيانات الأساسية
   - قائمة منسدلة للفصل الدراسي
   - واجهة قابلة للتمرير (Scrollable)

2. **نواتج التعلم (Learning Outcomes)**
   - نموذج إضافة CLO مع جميع الحقول
   - قائمة عرض بتنسيق جدول (Treeview)
   - أزرار إضافة/حذف/مسح
   - عرض الفئات (Knowledge/Skills/Values)
   - حقول معيار النجاح والمستوى المستهدف

3. **الموضوعات (Topics)**
   - نموذج إضافة موضوع
   - قائمة عرض مرتبة حسب الرقم
   - إدخال ساعات الاتصال
   - أزرار إدارة

4. **أنشطة التقييم (Assessment Activities)**
   - نموذج إضافة نشاط
   - حقول الدرجة والنسبة المئوية والتوقيت
   - قائمة عرض الأنشطة
   - أزرار إدارة

5. **جدول المواصفات (Table of Specifications)**
   - واجهة استعداد (مُعدة للتطوير المستقبلي)
   - رسالة توضيحية

#### المميزات الرئيسية:
- 🎨 تصميم احترافي يتبع ألوان الجامعة
- 🌐 دعم كامل للغتين (العربية/الإنجليزية)
- ✅ التحقق من البيانات قبل الحفظ
- 💾 الحفظ التلقائي قبل إكمال المرحلة
- 📊 عرض البيانات في جداول منظمة
- 🔔 رسائل تأكيد وتحذير وأخطاء
- 📱 واجهة سريعة الاستجابة (Responsive)
- 🔄 تحديث فوري للقوائم

## 🔄 سير العمل (Workflow)

### المرحلة الأولى - مدير البرنامج:

```
1. مدير البرنامج يقوم بـ:
   ├─ إنشاء مقرر جديد
   ├─ إدخال معلومات المقرر الأساسية
   ├─ إضافة نواتج التعلم (CLOs)
   ├─ إضافة موضوعات المقرر
   ├─ إضافة أنشطة التقييم
   ├─ بناء جدول المواصفات (تلقائي)
   └─ إكمال المرحلة الأولى

2. النظام يقوم بـ:
   ├─ التحقق من اكتمال جميع البيانات
   ├─ التحقق من صحة المجاميع (يجب أن تساوي 100)
   ├─ التحقق من ربط الموضوعات بالنواتج
   ├─ التحقق من ربط الأنشطة بالموضوعات
   ├─ حفظ البيانات
   └─ تغيير حالة المقرر إلى "مكتمل المرحلة 1"

3. منسق المقرر يقوم بـ:
   ├─ مراجعة بيانات المقرر
   ├─ اعتماد المرحلة الأولى
   │  (أو رفضها مع ذكر السبب)
   └─ البدء في المرحلة الثانية
```

## ✅ التحققات والقيود (Validations & Constraints)

### 1. معلومات المقرر:
- ☑️ جميع الحقول الأساسية إلزامية
- ☑️ رمز المقرر فريد
- ☑️ تنسيق العام الأكاديمي صحيح

### 2. نواتج التعلم:
- ☑️ الكود فريد وغير مكرر
- ☑️ الوصف إلزامي
- ☑️ الدرجة > 0
- ☑️ معيار النجاح بين 0 و 100
- ☑️ المستوى المستهدف بين 0 و 100
- ☑️ مجموع درجات CLOs = 100

### 3. الموضوعات:
- ☑️ رقم الموضوع فريد
- ☑️ العنوان إلزامي
- ☑️ ساعات الاتصال > 0
- ☑️ مجموع ساعات توزيع CLOs = ساعات الاتصال
- ☑️ مجموع درجات الموضوعات = 100

### 4. أنشطة التقييم:
- ☑️ اسم النشاط فريد
- ☑️ الدرجة > 0
- ☑️ النسبة المئوية بين 0 و 100
- ☑️ مجموع درجات الأنشطة = 100
- ☑️ مجموع النسب المئوية = 100%
- ☑️ كل نشاط يقيس على الأقل CLO واحد

### 5. جدول المواصفات:
- ☑️ كل موضوع يرتبط بـ CLOs
- ☑️ كل CLO يرتبط بأنشطة تقييم
- ☑️ توزيع الدرجات متسق

## 🔧 التكامل مع النظام الحالي

### 1. التكامل مع نظام المستخدمين:
- ✅ استخدام `current_user` من جلسة المستخدم
- ✅ التحقق من الأدوار (Roles) قبل السماح بالعمليات
- ✅ تسجيل من قام بالإنشاء والتعديل والاعتماد

### 2. التكامل مع نظام التحكم في الصلاحيات:
- ✅ مدير البرنامج: إنشاء وتعديل بيانات المقرر
- ✅ منسق المقرر: اعتماد أو رفض المرحلة الأولى
- ✅ حماية البيانات المعتمدة من التعديل غير المصرح

### 3. التكامل مع الواجهة الرئيسية:
```python
# مثال على الاستدعاء من الواجهة الرئيسية:
from dialogs.stage1_course_dialog import Stage1CourseDialog
from managers.course_manager import CourseManager

# إنشاء مدير المقررات
course_manager = CourseManager()

# فتح نافذة إدارة المقرر
dialog = Stage1CourseDialog(
    parent=main_window,
    course_manager=course_manager,
    current_user=logged_in_user,
    course_id=None,  # None للمقرر الجديد
    language='ar'
)
```
