🚀 كيفية الاستخدام - HOW TO USE
═══════════════════════════════════════════════════════════════════════════════

الخطوة 1: تشغيل البرنامج
Step 1: Run Application
───────────────────────
• استخدم START_WITH_VENV.bat (إذا كنت تستخدم .venv)
• Use START_WITH_VENV.bat (if using .venv)
• أو START_HERE.bat (بدون بيئة افتراضية)
• Or START_HERE.bat (without venv)

الخطوة 2: تسجيل الدخول كمدير
Step 2: Login as Admin
───────────────────────
Username: admin
Password: admin123

الخطوة 3: إضافة منسق برنامج
Step 3: Add Program Coordinator
───────────────────────
1. اختر قائمة "الإدارة" → "إدارة المستخدمين"
   Select "Admin" menu → "User Management"

2. أضف مستخدم جديد أو عدّل موجود
   Add new user or edit existing

3. اختر دور "منسق البرنامج" (program_manager)
   Select "Program Coordinator" role

4. احفظ المستخدم
   Save user

الخطوة 4: إنشاء برنامج أكاديمي
Step 4: Create Academic Program
───────────────────────
1. اختر قائمة "الإدارة" → "إدارة البرامج الأكاديمية"
   Select "Admin" → "Academic Programs"
   أو اضغط Ctrl+P

2. اضغط "➕ برنامج جديد"
   Click "➕ New Program"

3. املأ المعلومات:
   Fill information:
   - اسم البرنامج (عربي) * - Program Name (Arabic) *
   - اسم البرنامج (إنجليزي) * - Program Name (English) *
   - الكلية - College
   - القسم - Department
   - منسق البرنامج * - Program Coordinator *

4. اضغط "✓ حفظ"
   Click "✓ Save"
