🚀 كيفية تشغيل التطبيق:

1. افتح Command Prompt أو Terminal في مجلد المشروع

2. شغل الأمر التالي:
   streamlit run streamlit_app.py

3. سيفتح المتصفح تلقائياً على العنوان:
   http://localhost:8501

4. إذا لم يفتح المتصفح، افتحه يدوياً واكتب العنوان أعلاه

📝 ملاحظات مهمة:

1. تأكد من تثبيت جميع المكتبات المطلوبة:
   pip install -r requirements_streamlit.txt

2. لا تنسى تغيير كلمات المرور عند النشر على الإنترنت

3. التطبيق يستخدم قاعدة بيانات SQLite الموجودة

4. يمكن التبديل بين العربية والإنجليزية من الواجهة

5. التطبيق يدعم جميع المتصفحات الحديثة
