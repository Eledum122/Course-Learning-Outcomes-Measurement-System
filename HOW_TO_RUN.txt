═══════════════════════════════════════════════════════════════
الطريقة 1: ملف Batch (الأسهل)
═══════════════════════════════════════════════════════════════

1. افتح المجلد:
   d:\Dropbox\CLOs_Measurement_System_03

2. اضغط مرتين على ملف:
   run.bat

3. ستظهر نافذة تسجيل الدخول


═══════════════════════════════════════════════════════════════
الطريقة 2: Python مباشرة
═══════════════════════════════════════════════════════════════

1. افتح Command Prompt أو PowerShell

2. اذهب للمجلد:
   cd d:\Dropbox\CLOs_Measurement_System_03

3. شغل البرنامج:
   python main.py

4. ستظهر نافذة تسجيل الدخول


═══════════════════════════════════════════════════════════════
الطريقة 3: سكريبت run_app.py
═══════════════════════════════════════════════════════════════

1. افتح Command Prompt أو PowerShell

2. اذهب للمجلد:
   cd d:\Dropbox\CLOs_Measurement_System_03

3. شغل:
   python run_app.py

الطريقة 4: من داخل IDE (VS Code, PyCharm, etc)
═══════════════════════════════════════════════════════════════

1. افتح المجلد في IDE

اسم المستخدم: admin

═══════════════════════════════════════════════════════════════
ملاحظات مهمة
═══════════════════════════════════════════════════════════════

1. تأكد من تثبيت المكتبات المطلوبة:
   pip install reportlab pillow arabic-reshaper python-bidi

2. إذا لم تظهر نافذة تسجيل الدخول:
   - تأكد من Python مثبت بشكل صحيح
   - حاول تشغيل test_startup.py للتحقق من النظام
   - تحقق من أن tkinter مثبت مع Python

3. لاختبار النظام قبل التشغيل:
   python test_startup.py


═══════════════════════════════════════════════════════════════
حل المشاكل الشائعة
═══════════════════════════════════════════════════════════════

المشكلة: نافذة تسجيل الدخول لا تظهر
الحل:
  - شغل من Command Prompt بدلاً من النقر المزدوج
  - استخدم run.bat بدلاً من main.py مباشرة

المشكلة: خطأ في الاستيراد
الحل:
  - ثبت المكتبات: pip install -r requirements.txt
  - أو: pip install reportlab pillow arabic-reshaper python-bidi

المشكلة: خطأ في الترميز (encoding error)
الحل:
  - استخدم run.bat الذي يضبط الترميز تلقائياً
  - أو شغل: chcp 65001 قبل python main.py


═══════════════════════════════════════════════════════════════
بعد تسجيل الدخول
═══════════════════════════════════════════════════════════════

1. ستجد قائمة جديدة في شريط القوائم: 🛡️ الإدارة

2. لإضافة المستخدمين:
   الإدارة → إدارة المستخدمين (Ctrl+U)

3. قائمة الإدارة تحتوي على:
   - إدارة المستخدمين (Ctrl+U)
   - النسخ الاحتياطي (Ctrl+B)
   - سجل التدقيق (Ctrl+Shift+A)
   - إعدادات النظام
